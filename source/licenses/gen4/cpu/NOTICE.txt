Direct Gen4 CPU runtime

The Gen4 runtime links the official FEX project at revision
f2b679f6028ce1c38875233aecfcf5d3f8ebecec from the pinned repository submodule
source/3rdparty/fex-gen4. Source: https://github.com/FEX-Emu/FEX
The pinned translator source is unmodified. The embedding, signal integration
and host entry points are provided by this project. Android requires 4096-byte
host pages. The macOS build applies a separate Darwin host overlay for
MAP_JIT, per-thread write protection, host system APIs and Apple Silicon's
16384-byte pages. The overlay is built separately from the pinned source.
The separate PS5 process retains its own CPU build and host adaptation.
